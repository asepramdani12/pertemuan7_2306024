CRUD merupakan singkatan dari Create (menambahkan data), Read
menampilkan data), Update (mengubah data) dan Delete
menghapus data). CRUD merupakan konsep dasar dalam
pengolahan data pada aplikasi, baik web maupun mobile.
- StatefulWidget
Stateful Widget adalah widget yang memiliki state (data) yang bisa
berubah selama aplikasi berjalan.
- ListView
ListView merupakan widget dalam flutter yang digunakan untuk
menampilkan data dalam bentuk daftar (list).
